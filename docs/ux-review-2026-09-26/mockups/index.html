Visual and UX review · 26 September 2026
Nine recommendations · Review prototypes

Keep the character. Make the next action clear.

The paper-and-navy identity works. Repeated control borders, long setup areas, and weak action priority make common work harder to scan. Start with the narrow rule editor, capture setup, list actions, and Tealium.

These mockups use sample data. They do not change the extension. Open each view to test its local controls. Use the “Current interface” link to compare the fresh browser capture.
